K4 VM-Tippning 2026 - PWA-version

Ladda upp/ersätt dessa filer i GitHub-repot:
- index.html
- manifest.webmanifest
- service-worker.js
- mappen icons/
- VM BAnner.png

Behåll även din facit.json i repot.

Efter uppladdning:
1. Vänta 1-2 minuter tills GitHub Pages publicerat.
2. Öppna https://and1983.github.io/k4-vm2026/
3. Tryck Ctrl+F5 på dator.

Installera på iPhone:
- Öppna sidan i Safari.
- Tryck Dela-knappen.
- Välj Lägg till på hemskärmen.

Installera på Android:
- Öppna sidan i Chrome.
- Tryck menyn med tre prickar.
- Välj Installera app eller Lägg till på startskärmen.

Installera på Windows/Chrome/Edge:
- Öppna sidan.
- Klicka installationsikonen i adressfältet eller menyn.
