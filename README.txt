# K4 VM2026 - GitHub Pages med gemensamt facit

Ladda upp/ersätt dessa filer i GitHub-repot `k4-vm2026`:

- `index.html`
- `facit.json`

## Uppdatera facit efter matcher
1. Öppna appen: https://and1983.github.io/k4-vm2026/
2. Gå till Admin och lås upp med lösenordet.
3. Fyll i resultaten.
4. Klicka `Ladda ner facit.json`.
5. Gå till GitHub-repot och ladda upp filen `facit.json` i roten. Välj att ersätta befintlig fil.
6. Vänta någon minut och uppdatera appen. Då ser alla samma facit och topplista.

Tips: Om du inte ser senaste facit direkt, tryck Ctrl+F5 på dator eller uppdatera sidan på mobilen.
